# XO Platform - دليل الميزات والصلاحيات للعرض التجاري

هذا الملف يشرح ميزات منصة XO من زاوية تجارية وعملية، وليس من زاوية تقنية. الهدف أن يساعدك في عرض المشروع أمام عميل، إدارة حضانة، مستثمر، أو فريق تشغيل.

## فكرة المنصة

منصة XO هي نظام تشغيل متكامل للحضانات. تجمع الإدارة اليومية، التواصل مع أولياء الأمور، حضور الأطفال، التقارير، المالية، الموظفين، الفعاليات، والمحتوى في مكان واحد.

القيمة الأساسية للمنصة هي أن كل مستخدم يرى ما يخصه فقط حسب دوره:

- الإدارة العليا ترى الصورة الكاملة للحضانة أو مجموعة الحضانات.
- مدير الفرع يدير العمليات اليومية داخل حضانته.
- مدير المالية يرى المدفوعات والتقارير المالية.
- مدير الموارد البشرية يرى الموظفين والتعيينات.
- المعلم يرى فصله، الحضور، التقارير، الأنشطة، والتواصل المرتبط بالأطفال.
- ولي الأمر يرى بيانات طفله، التقارير، الصور، الفواتير، الموافقات، والإشعارات.

## الأدوار الرئيسية في النظام

| الدور | الاستخدام التجاري | القيمة |
|---|---|---|
| المدير العام XO | إدارة كل الحضانات والفروع | رؤية مركزية، رقابة، وتحكم كامل |
| مدير السلسلة | متابعة عدة فروع ضمن نفس المجموعة | توحيد التشغيل بين الفروع |
| مدير الفرع | إدارة حضانة واحدة | تشغيل يومي أسرع وأوضح |
| مدير مالي | متابعة الإيرادات والفواتير والمدفوعات | تقليل الأخطاء وتحسين التحصيل |
| مدير موارد بشرية | متابعة الموظفين والتعيين والرواتب | تنظيم الفريق وتقليل العمل اليدوي |
| معلم | إدارة الفصل والتقارير اليومية والأنشطة | رفع جودة التواصل مع أولياء الأمور |
| ولي أمر | متابعة الطفل والدفع والموافقات | ثقة أعلى وتجربة أفضل للأسرة |

## سيناريو عرض مقترح للعميل

1. ابدأ بتسجيل الدخول كمدير عام واعرض لوحة الإدارة.
2. انتقل إلى الحضور لتوضيح متابعة اليوم الدراسي.
3. افتح ملف طفل واعرض البيانات الصحية والتقارير اليومية.
4. اعرض تجربة ولي الأمر: التقارير، الصور، الفواتير، والموافقات.
5. اعرض تجربة المعلم: الحضور، التقرير اليومي، ورفع صورة نشاط.
6. افتح المالية واعرض الفواتير والتحصيل.
7. اختتم بالصلاحيات: وضح أن كل دور يرى ما يخصه فقط، وأن الإدارة تستطيع ضبط الوصول حسب المسؤولية.

## الرسالة التجارية المختصرة

منصة XO تقلل العمل اليدوي داخل الحضانة، ترفع جودة التواصل مع أولياء الأمور، تعطي الإدارة رؤية تشغيلية ومالية واضحة، وتحمي البيانات عبر صلاحيات دقيقة لكل دور.
